# AETHERIUM — механика неба

Солнечная система по настоящим орбитам, в наглядном или истинном масштабе, с космическими
событиями — и всё это будто снято старой кинокамерой: объектив и плёнка реагируют на то,
куда вы смотрите. React 19, TypeScript, Vite, Three.js.

## Запуск

1. Node.js 20.19+ или 22.12+.
2. `npm install`
3. `npm run dev` → http://127.0.0.1:5177

**Один файл без сервера:** `npm run build` собирает `dist/index.html` со всеми скриптами,
стилями и шрифтами внутри. Его можно открыть двойным щелчком на любом компьютере без сети.
Нужны WebGL 2 и аппаратное ускорение.

## Управление

| Действие | Как |
|---|---|
| Вращать вид | левая кнопка мыши / один палец |
| Приблизить | колесо / два пальца |
| Сдвинуть центр обзора | правая кнопка |
| Сведения о теле | щелчок по телу, подписи или пункту списка |
| Перелёт к телу | пункт в списке слева или «Лететь к телу» в карточке |
| Пауза | пробел или кнопка |
| Время назад | кнопка перемотки слева от паузы |
| Скорость | ползунок: от реального времени до 1000 лет в секунду |
| Закрыть панель | Esc |

## Что моделируется честно

- **Орбиты.** Кеплеровы элементы JPL (Standish, таблица 1) с вековыми поправками: эллипсы,
  наклоны, повороты перигелиев и узлов. Орбиты перестраиваются по ходу времени — при быстрой
  перемотке видно, как они медленно поворачиваются. Проверка: противостояния Марса (16.01.2025),
  Юпитера (10.01.2026), Сатурна (21.09.2025) и нижнее соединение Венеры сходятся с расчётом
  точнее 0,2°. Вне 1800–2050 годов — экстраполяция, интерфейс об этом предупреждает.
- **Луна** — по элементам Шлейтера с регрессией узла (18,6 года) и прецессией перигея.
- **Оси вращения** — полюса и скорости IAU (Archinal et al. 2018): Уран лежит на боку,
  Венера вращается обратно.
- **Пояс астероидов** — 7000 тел со своими орбитами и щелями Кирквуда; уравнение Кеплера
  для них решает видеокарта.
- **Истинный масштаб** — расстояния и размеры в одной мере (1 единица = 100 000 км).
  Земля с орбиты Марса меньше пикселя, поэтому тела отмечены кружками.

## Что условно

- **Наглядный масштаб** сжимает расстояния (∝ r^0,5) и радиусы (∝ R^0,42), чтобы вся
  система помещалась в кадр. Форма орбит при этом сохраняется.
- **События** — художественные сценарии. Солнце слишком лёгкое для сверхновой, чужих флотов
  не наблюдали. Гравитационная волна показана с настоящей формой искажения, но амплитуда
  увеличена в 10²⁰ раз.
- Поверхности планет процедурные: узнаваемые, но не карты.

## Объектив и плёнка

Помехи накладываются одним шейдером на картинку сцены и зависят от происходящего:

| Где | Что происходит с изображением |
|---|---|
| Солнце в кадре | пересвет, ореол, марево горячего воздуха, горячие пиксели |
| Юпитер вблизи | «радиация» — вспыхивающие пиксели, зерно |
| Уран, Нептун | иней по краям линзы, холодный оттенок |
| Далеко от Солнца | недодержка, зерно, фокус «ищет», у края системы — слабый сигнал |
| Перелёт | расфокус, дрожь кадра, хроматическая аберрация |
| Быстрая перемотка | мерцание и царапины |
| Время от времени | царапины, пыль, засветка, короткая потеря сигнала |

В сильные моменты сбой выходит на весь экран, вместе с интерфейсом: прожог плёнки,
засветка добела, смена кадра с перфорацией, «снег». Смена масштаба прячется за такой сменой
кадра. Силу помех можно убавить или выключить кнопкой с плёнкой.

## Структура кода

```
src/
  data/        справочник тел, орбитальные элементы, каталог событий
  physics/     уравнение Кеплера, время, перевод масштабов
  engine/      Observatory (кадр, команды), камера, часы, качество, хранилище состояния
  scene/       тела, орбиты, пояс астероидов, звёзды, подписи, текстуры
  lens/        шейдер объектива, свечение, режиссёр помех, пики на весь экран
  events/      дирижёр событий и 12 сценариев (по файлу на сценарий)
  ui/          компоненты интерфейса
  audio/       синтезированный фон
  styles/      оформление
```

Покадровые величины (дата, прогресс события, расстояния) пишутся в DOM напрямую, мимо React:
интерфейс перерисовывается только от действий человека.

node tools/shoot.cjs                          # снимки ключевых состояний в tools/shots
